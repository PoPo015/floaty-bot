한 줄 임베드

다른 사이트의 </body> 위에 아래 한 줄을 추가하면 됩니다.

<script src="https://popo015.github.io/floaty-bot/widget.js" defer></script>

특징

  • Shadow DOM 격리 — 호스트 페이지 CSS와 충돌 없음
  • 단일 IIFE 번들 — 의존성 0, gzip ~87KB
  • 둥둥 떠다니는 SVG 로봇 캐릭터 + 말풍선 hint
  • 현재는 mock 응답. 실제 LLM 연동은 mockApi.ts만 교체하면 끝
